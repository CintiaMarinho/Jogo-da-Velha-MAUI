# 🎮 Jogo da Velha MAUI

## 📌 Sobre o projeto

Aplicativo do Jogo da Velha desenvolvido utilizando .NET MAUI e C#, como atividade prática de desenvolvimento de aplicativos.

O projeto foi desenvolvido no Visual Studio 2026 e tem como objetivo aplicar conhecimentos de programação e desenvolvimento de interfaces gráficas.

## 🎯 Objetivo

Desenvolver um aplicativo do Jogo da Velha utilizando recursos de programação e interface gráfica.

## 🛠️ Tecnologias utilizadas

- C#
- .NET MAUI
- XAML
- Visual Studio 2026
- Git
- GitHub

## 🎮 Funcionalidades

- Interface gráfica do Jogo da Velha.
- Tabuleiro com posições para os jogadores.
- Utilização de X e O durante a partida.

## 📂 Estrutura do projeto

- `App.xaml` — configuração inicial do aplicativo.
- `AppShell.xaml` — estrutura de navegação.
- `MainPage.xaml` — interface principal.
- `MainPage.xaml.cs` — código C# da página principal.
- `MauiProgram.cs` — configuração do aplicativo.
- `Platforms` — arquivos específicos das plataformas.
- `Resources` — recursos utilizados no aplicativo.

## ▶️ Como executar o projeto

1. Baixe ou clone este repositório.
2. Abra a solução no Visual Studio.
3. Aguarde o carregamento do projeto.
4. Selecione o dispositivo ou emulador disponível.
5. Execute o aplicativo.
